Panel index

1. Explicit length origin

rotate(90) about origin 100,100: the rect pivots on the crosshair and its center stays put.

viewBox: none

2. Keyword origin, viewBox x2

"center" resolves in local units (50,50) -> device (100,100), not at the device corner.

viewBox: 0 0 100 100

3. Nested group, local origin

Parent translate(40,50); child rotates about local (40,40). The parent then moves the rotated result.

viewBox: none

4. transform-box: fill-box

"center" targets the rect bounding box, so off-center geometry rotates about its own middle.

viewBox: none

5. Percentage origin in group

50% 50% references the local viewport inside the translated group; the axis travels with the group.

viewBox: none

6. Composition order

Nested translate(110,110) then rotate(90): rotation acts first on geometry, translation moves the result.

viewBox: none

7. Invalid origin isolation

transform-origin="garbage" on the red rect is ignored; the blue sibling renders exactly where declared.

viewBox: none

8. Reused node keeps position

One rotated group is instantiated twice with use; both copies show identical footprints at their own x/y.

viewBox: none
