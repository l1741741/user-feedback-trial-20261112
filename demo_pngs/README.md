# Transform-origin demo images

These PNGs are generated by `../demo_transform_origin.py` from small,
font-free SVG scenes. They exist so the geometric results can be checked by
eye: every scene shows the unrotated outline (dashed), the transformed shape
(solid) and, where relevant, the rotation origin (blue dot).

Regenerate them with:

```bash
.venv/bin/python demo_transform_origin.py
```

or inspect the SVG source with:

```bash
.venv/bin/python demo_transform_origin.py --stdout
```

| File | Shows |
| --- | --- |
| `transform_origin_centres.png` | The same rect and rotation with the default `0 0` origin (swings away from its outline) versus `fill-box` + `50% 50%` (rotates in place) |
| `transform_origin_asymmetric.png` | One off-centre rectangle rotated by `rotate(35)` about all four corners |
| `transform_origin_layers.png` | Two nested groups, each rotating about its own box centre, with translucent fills showing the layer order |
| `transform_origin_ordering.png` | `translate(180,40) scale(1.4)` versus `scale(1.4) translate(180,40)` from the same start |
| `transform_origin_use_reuse.png` | One referenced rectangle placed twice with a centred and a corner origin |

The same geometry is asserted to the pixel in
`../cairosvg/test_transform_origin.py`. See `../TRANSFORM-ORIGIN.md` for the
supported syntax, reference boxes and limitations.
