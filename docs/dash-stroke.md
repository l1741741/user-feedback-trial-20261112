# 描边虚线（stroke dashing）的解析与绘制

本文说明 CairoSVG 对 `stroke-dasharray` 与 `stroke-dashoffset` 的处理规则、
背后的 SVG 语义，以及对既有合法输入的兼容性。它描述的是**可观察的行为契约**，
不是某份固定实现步骤；具体代码见 `cairosvg/helpers.py` 中的
`parse_dash_array` / `parse_dash_offset` 与 `cairosvg/surface.py` 的调用处。

## 1. 为什么需要改

旧逻辑把属性字符串直接按空白拆成数字后交给 Cairo 的 `set_dash`，存在三类问题：

1. **非法值会让整个渲染失败。** 含负数、或全部为零的数组会让 Cairo 抛出
   `CAIRO_STATUS_INVALID_DASH`。该错误会污染当前上下文，使同一上下文里后续的
   所有绘制都失败——表现为“后面的实线节点也画不出来”。
2. **相位与单位不稳定。** 百分比、`em/ex/ch`、物理单位、科学计数、负偏移等
   输入没有统一的校验口径；奇数长度列表依赖 Cairo 未在 SVG 层面承诺的循环
   行为，设计稿与导出结果可能对不上。
3. **禁用描边时路径残留。** 填充使用 `fill_preserve()` 保留路径以便随后描边；
   当描边被禁用（全零数组）时若不主动丢弃路径，下一个节点的 `stroke()` 会把
   残留路径连同自己的路径一起描出来。

## 2. 行为契约

| 输入情形 | 结果 |
| --- | --- |
| 属性缺省 / `none` | 实线（不描虚线），并显式清空上下文上的虚线状态 |
| 偶数个非负长度 | 按“画、空、画、空……”循环 |
| 奇数个长度 | 先把列表重复一遍，再按偶数列表处理（SVG 语义） |
| 单个长度 `L` | 等价于 `L,L`（等长的画/空） |
| 含零项但不全为零 | 零项保留，只表示“这一段不产生墨/不产生空隙” |
| 全部为零（含单个 `0`） | **禁用描边**，该节点不产生任何描边墨迹，填充不受影响 |
| 含负数或非有限值（`nan`/`inf`/`1e999`） | 视为非法属性，忽略它并回退为实线 |
| 缺省或非有限的 `stroke-dashoffset` | 偏移按 `0` 处理 |

### 2.1 单位与路径长度的关系

- 每个长度都经由统一的尺寸解析得到**用户单位**浮点数：无单位数字与科学计数
  （`1e1`、`1.5e2`）直接转浮点；`em/ex/ch` 相对当前字号；`pt/pc/mm/cm/in` 按
  DPI 换算；百分比按 SVG 视口归一化对角线
  `hypot(宽, 高) / √2` 解析——与 CairoSVG 既有 `size()` 的默认参考一致。
- 虚线长度与偏移都在**用户空间**度量，随当前变换矩阵（CTM）一起缩放。例如
  `scale(2)` 下，`stroke-width:3` 渲染为 6 设备像素，`10,5` 的虚线节奏渲染为
  20/10 设备像素。`test_dash.py::test_scaled_stroke_width_and_dash_pattern`
  锁定了这一点。
- 偏移以一个完整图案周期为模，因此 `+周期` 与 `-周期` 都与零偏移等价；测试
  `test_offset_by_a_full_cycle_is_identity` 保证该关系可复现。负偏移合法，
  Cairo 内部会把它折算成周期内的等效相位。

### 2.2 接点与子路径

- 一条 path/polyline 的各段属于同一个路径，**相位沿弧长累计**，折线拐角处不
  重置，因此不会在接点“跳一截”。
- 每个新子路径（`M`/`m` 开启）从各自的起点重新开始图案周期——这与 SVG 2
  “虚线在每个子路径起点重新开始”的规定一致。
- 闭合路径（`Z`/`close`、`polygon`、`rect`、`circle`、`ellipse`）的图案沿
  整个周长延续，闭合段同样参与虚线分布。

### 2.3 继承与局部覆盖

`stroke-dasharray` 是可继承属性，CairoSVG 的节点树在构造时已把父节点的值传给
子节点。在此基础上：

- 子节点给出自己的 `stroke-dasharray` 时完全覆盖继承值；
- 子节点写 `stroke-dasharray="none"`（或等价的缺省）会回到实线，**不会**沿用
  父级的虚线；
- 每个节点绘制时都会显式设置或清空虚线状态，非法值不再污染上下文，因此后续
  实线兄弟节点保持实线。

## 3. 对既有合法输入的兼容性

修复只改变**原本未定义或会出错**的情形，所有能正常出图的合法输入保持不变：

- 合法的偶数/奇数非负数组、各种单位、正负偏移，渲染像素与之前一致。奇数列表
  之前恰好依赖 Cairo 的循环得到与 SVG 倍增相同的节奏（数学上等价），现在显式
  倍增，输出不变但不再依赖未承诺行为；`test_odd_list_matches_its_doubled_form`
  同时比较了两种写法的像素结果。
- `none` 与缺省本来就画实线，行为不变，只是改为显式 `set_dash([])`。
- 行为发生变化的只有两类**异常输入**：
  - 负数/非有限数组：旧行为是抛异常、中断整张图；新行为是回退实线（与主流浏览
    器对非法 `stroke-dasharray` 的容错一致）。
  - 全零数组：旧行为因 `sum(dashes)==0` 不调用 `set_dash` 而画出实线；新行为
    按 SVG 2 “全零表示无可绘制虚线、禁用描边”处理为不描边。填充、标记等其余
    绘制不受影响。
- 全零禁用描边时会主动 `new_path()` 清掉 `fill_preserve()` 保留的路径，修掉了
  “后续实线节点沿用前一节点路径”的状态泄漏（见
  `test_disabled_stroke_does_not_retain_its_path_for_later_nodes`）。

## 4. 如何自行验证

- 单元与像素级回归：

  ```bash
  DYLD_FALLBACK_LIBRARY_PATH=/path/to/cairo/lib \
      .venv/bin/python -m pytest -q cairosvg/test_dash.py
  ```

  测试覆盖：解析规则（奇列表、零项、负数、非有限值、百分比、科学计数、单位、
  偏移）、起止位置的 PNG 像素测量、继承与 `none` 覆盖、折线拐角、多子路径、
  闭合路径、缩放线宽、空/退化路径、病态数组不卡死，以及重复导出字节一致。

- 独立可运行的可视化例子（带 10 单位参考刻度，能直接读出每段实/空白的起止）：

  ```bash
  DYLD_FALLBACK_LIBRARY_PATH=/path/to/cairo/lib \
      .venv/bin/python examples/dash_stroke_demo.py /tmp/dash_stroke_demo
  ```

  生成 `dash_stroke_demo.svg` 与 `.png`，并打印每行实测的墨迹区间（像素即用户
  单位坐标）。
