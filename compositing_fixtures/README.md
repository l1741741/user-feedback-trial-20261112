# Group compositing fixtures and visual comparison

These fixtures exercise `opacity` on containers (group semantics) versus on
children (per-element semantics), including nesting, clipping, masks and
repeated export. They are rendered by
`cairosvg/test_group_compositing.py`, which asserts exact interior pixel
values.

`compare.png` is a visual reference sheet, generated by
`tools/make_compositing_figure.py`:

- **Row 1** — the same overlapping red/blue squares rendered with
  `<g opacity="0.5">` (left) and with `opacity="0.5"` on each child (right).
  The overlap band differs: with group opacity it equals the blue-only band
  (opaque blue covers red before alpha); with per-child opacity it is a third,
  darker blend.
- **Row 2** — nested groups, group + `clip-path`, group + mask.
- **Row 3** — `use` inheriting opacity, empty/zero-opacity group followed by a
  sibling, mask reuse at two sizes.

`pixels.txt` lists the sampled pixel values so a regression can be diagnosed
without opening the image.

Regenerate:

```bash
export DYLD_FALLBACK_LIBRARY_PATH="<cairo libs>"
.venv/bin/python tools/make_compositing_figure.py
```
